# Text Embedding Similarity Search

This example demonstrates the core concept of vector embeddings and similarity search, which are fundamental to high-performance vector indexes like HNSW and IVF-PQ. It converts text documents and a query into numerical vectors (embeddings) using a pre-trained model, then calculates cosine similarity to find the most relevant documents.

## Language

`python`

## How to Run

1. Install dependencies: `pip install sentence-transformers numpy`
2. Run the script: `python main.py`
